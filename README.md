# AI Nation 2030 · MAHIR

Grand Final deck, NICTSeD 2026 CyberSAFE Challenge Trophy.
SMK St Bernadette's Convent, Perak.

Single-file HTML deck. 30 slides: 21 stage slides plus 9 evidence-bank slides for Q&A. Framework: MAHIR, five blocks and nine mechanisms.

## Controls

| Key | Action |
|---|---|
| ← → Space | Previous / next slide |
| H or ⌂ HOME button | Back to slide 1 |
| / | Focus search (slides, cards, sources, notes) |
| D | Toggle dark / light theme |
| S | Toggle side panel |
| N | Presenter notes |
| T | Start / reset timer |
| Q | Jump to evidence bank (slide 22) |
| F | Fullscreen |
| Esc | Close popup |

Click any card marked + to open its detail popup. Direct link to a slide: `index.html#15`.

## Deploy

Served from the `main` branch root via GitHub Pages. The file is self-contained; only Google Fonts (Poppins) is loaded externally and falls back to system fonts when offline.
